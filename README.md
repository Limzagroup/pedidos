# pedidos
LIMZA GROUP Pedidos

El catálogo combina las pestañas `Productos` y `cebra` del archivo de Google Sheets. `Productos` debe incluir `Código`, `Producto` y `Precio de venta` (marca y disponibilidad son opcionales). `cebra` debe incluir `Código`, `Descripción` y `Precio USD`; la columna `Empaque` es opcional y se muestra como presentación del producto y en el detalle del pedido.
