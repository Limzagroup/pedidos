# pedidos
LIMZA GROUP Pedidos

El catálogo combina las pestañas `Productos` y `cebra` del archivo de Google Sheets. `Productos` debe incluir `Código`, `Producto` y `Precio de venta` (marca y disponibilidad son opcionales). `cebra` debe incluir `Código`, `Descripción` y `Precio USD`; `Empaque` es opcional y se muestra junto a la descripción, `Imagen` puede incluir la URL de la foto de cada presentación, y `Subcategoría` es opcional y habilita el filtro por tipo de producto en la descarga. Para controlar disponibilidad en `cebra`, agrega una columna `Publicación`, `Publicado` o `Disponible`; los valores `No` y `No publicar` deshabilitan el producto. La descarga incorpora las imágenes de CEBRA listadas desde la fila 135 en adelante, siempre que el producto esté disponible.

La tasa USDT/VES muestra el último valor válido guardado en el dispositivo mientras consulta una actualización, y reintenta automáticamente si falla la conexión. Si no se puede actualizar el inventario, el catálogo guardado permanece visible sin mostrar un error de sincronización.

El carrito de pedidos se guarda localmente en el navegador y se restaura al regresar desde el catálogo digital o recargar la página. Se elimina al completar correctamente el pedido; los datos personales del formulario no se guardan.

El nombre del vendedor se valida contra la pestaña `VENDEDORES` antes de habilitar el envío del pedido y también se verifica en el servidor al guardar. Al modificar `script.js`, hay que actualizar el proyecto y volver a desplegar el Web App de Apps Script para activar esta comprobación.

La pestaña `VENDEDORES` puede incluir columnas `Vendedor` (o `Nombre`) y `Correo` (o `Email`). Al registrar un pedido, se busca el vendedor sin distinguir mayúsculas ni acentos y se envía una copia del PDF sin los campos operativos de Picking, bulto, pedido, nota y guías. Si falta una coincidencia o el correo no es válido, el pedido y el comprobante principal se procesan igualmente y se informa al usuario.

El PDF deja que el motor de impresión distribuya las filas según el espacio disponible, repite el encabezado de la tabla en cada página y evita cortar una fila entre páginas.

El apartado `Catálogo digital` está aislado en `catalogo.html`. Agrupa las pinturas CEBRA por línea, permite seleccionar solo los colores y presentaciones disponibles, cambia la imagen según la presentación cuando hay una URL en `Imagen` y actualiza el código SKU y el precio con cada selección. Los demás productos muestran su marca en la parte superior de la tarjeta, junto con imagen, código, descripción y precio. Es de solo lectura y no incluye controles para agregar artículos al pedido. Las tres páginas comparten el menú de navegación y la preferencia de tema.

Para que las páginas y sus funciones operen en producción, publica juntas `index.html`, `index-app.js`, `catalogo.html`, `descargar-catalogo.html`, `catalog-utils.js`, `navigation.css`, `navigation.js`, `usdt-rate.js`, `muestras-color.js`, `Plantilla_Catalogo.pdf`, `LIMZAGROUP_LOGO.webp`, `favicon.ico` y `Open_Graph.png` en GitHub Pages. Al actualizar `usdt-rate.js`, incrementa el parámetro de versión `?v=` en las tres páginas para evitar que el navegador reutilice una copia anterior.

La opción `Descargar catálogo`, disponible desde el menú compartido, permite descargar el PDF completo o elegir marcas específicas; cuando se selecciona CEBRA, también permite filtrar por la columna opcional `Subcategoría` (o `Familia` / `Tipo producto`) de la pestaña `cebra`. Combina el catálogo público con los productos CEBRA disponibles de la hoja de pedidos y completa los logos desde el directorio de marcas. El Web App de pedidos ofrece miniaturas en caché para imágenes de Drive compartidas públicamente; las imágenes sin miniatura disponible se obtienen del servicio actual del catálogo. Cuando el producto tiene empaque, lo añade a la descripción. Genera el archivo con `pdf-lib` sobre la plantilla original `Plantilla_Catalogo.pdf`, conserva su cuadrícula 3 × 5, distribución, bordes y numeración de página, y muestra muestras de color redondeadas en lugar de la fotografía para las pinturas reconocidas; los demás productos conservan su imagen.
